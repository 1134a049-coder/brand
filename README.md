# SUKIYA すき家 品牌期中專題簡報

本專題為大專院校品牌行銷課程之期中專案，嚴格遵循「5 頁投影片、5 分鐘限時」架構，以 **SUKIYA（すき家）** 為分析標的，完成品牌由來、五層次產品模型、廣告反推 TA、STP 與知覺圖、以及品牌個性擬人化分析。

---

## 📂 專案檔案清單

| 檔案名稱 | 說明 | 狀態 |
| :--- | :--- | :--- |
| **`brand_presentation.html`** | 簡報主程式（16:9 互動投影片、支援鍵盤翻頁、即時提詞稿與 PDF 下載） | ⭐ **必要核心** |
| **`sukiya廣告fb.jpg`** | 第 3 頁手機外框內引用的真實 Facebook 廣告圖片 | ⭐ **必要圖片** |
| **`sukiya_ad.jpg`** | 備用/原始廣告圖片素材 | 附屬素材 |
| **`presentation_enhancement_plan.md`** | 專案企劃書（4 輪標準加嚴之優化歷程與驗收指標） | 專案文檔 |
| **`lecture_transcript_and_guidelines.md`** | 課堂音檔梳理與評分標準規範（包含 5 頁核心規範、嚴禁事項與演講時間分配） | 專案文檔 |
| **`.gitignore`** | Git 排除設定（自動忽略超過 100MB 之課堂音檔 `上課錄音.aac`） | 系統設定 |

---

## 🚀 簡報瀏覽與操作說明

1. 下載後直接以瀏覽器（Chrome / Edge 等）開啟 `brand_presentation.html`。
2. **操作快捷鍵**：
   - `→` / `Space`：下一頁
   - `←`：上一頁
   - `P`：開啟 / 隱藏即時講稿提詞窗
   - 右上角「下載簡報 (PDF)」按鈕：可直接另存為 A4 / 16:9 簡報檔。
