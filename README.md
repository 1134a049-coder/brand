# SUKIYA すき家 品牌設計期中專題簡報 (13 頁 Canva 原生美學升級版)

> **專案名稱**：すき家 (SUKIYA) 品牌策略期中全維度解構  
> **指導教授**：國立台北商業大學 黃焜煌 老師  
> **受評組別**：第 20 組  
> **技術架構**：原生 HTML5 + Vanilla CSS + ES6 + 響應式 16:9 投影片 + 即時演講提詞抽屜（含 Q&A 提問防禦術）  
> **線上即時預覽 (Live Demo)**：👉 **[點此直接開啟線上簡報 (GitHub Pages)](https://1134a049-coder.github.io/brand/)**  

---

## 🌟 專案核心特點

1. **嚴格對齊導師（黃焜煌老師）評分尺規**：
   - 遵照「品牌冰山模型」，從水面下 90% 隱形策略（核心壁壘、客群痛點、價值主張、STP、KBF 知覺定位圖、品牌個性），一路推導至水面上 10% 外顯接觸點（品牌識別、實體接觸點、一致性檢核與體驗落地）。
   - 拒絕空泛描述，全篇注入 **Kotler 產品五層次**、**ZENSHO MMDS 全球垂直冷鏈**、**Loss-Leader（犧牲打）定價心理學**、**正中央黃金平衡甜蜜點（Sweet Spot）** 與 **盧廣仲人格原型神對標**。
2. **互動式演講提詞抽屜（Speaker Notes Drawer）**：
   - 支援鍵盤按 `P` 鍵隨時開啟/收合側邊講稿抽屜。
   - 13 頁投影片全數配置四大標準模組：
     - `【導師評分審查要點】`：明示該頁給分核心。
     - `【高分口頭演講逐字稿】`：精準控時 35~50 秒，直接切入核心講答案。
     - `【轉場引導話術】`：承上啟下，自然銜接下一頁。
     - `【導師尖銳提問防禦術】`：預判導師可能追問之刁鑽問題與高分應答範本。
3. **Canva 原生暖米色膠囊美學**：
   - 16:9 高清比例適配，沉浸式大螢幕投影，內建高畫質真實門市實景、知覺圖、官方廣告與盧廣仲對標圖。

## 🚀 簡報瀏覽與演講操作快捷鍵

1. 直接開啟 [線上簡報網址](https://1134a049-coder.github.io/brand/) 或本機開啟 `index.html`。
2. **快捷鍵控制**：
   - `→` / `Space`：切換至下一頁投影片。
   - `←`：返回上一頁投影片。
   - **`P`**：**開啟 / 關閉側邊「演講提詞稿與 Q&A 防禦抽屜」**。
   - `Esc`：快速關閉提詞抽屜。
   - 右上角 **「全螢幕展示」**：進入 16:9 沉浸式劇院模式。
   - 右上角 **「下載簡報 (PDF)」**：調用系統列印，另存為無邊框高畫質 PDF。
